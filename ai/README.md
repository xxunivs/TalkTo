# TalkTo AI 서버

가족의 통화 녹음과 설문으로 한 사람의 말투와 기억을 담은 페르소나를 만들고, 그 페르소나로 대화하는 AI 서버입니다.

```text
앱 → BE (talkto_api_server) → AI 서버 (/v1/...) → OpenAI, Fish Audio, ElevenLabs
```

BE가 로그인, 동의, 운영 DB 저장, 기억 검색을 맡고, AI 서버는 BE가 보낸 지시문, 기억, 목소리 ID로 답을 만듭니다.

## 페르소나 제작 파이프라인

| 단계 | 내용 |
|---|---|
| s0 설문 | 설문 작성본을 프롬프트 재료와 기억으로 변환 |
| s1 전사 | 녹음 전사, 화자 분리와 대상자 식별, 고유명사 교정 |
| s2 추출 | 인물, 민감도, 말투, 기억, 요약 분석 |
| s3 종합 | 기억 병합, 통찰 추출, 프롬프트 조립, 임베딩 생성 |
| s4 음성 | 대상자 음성 샘플 수집과 목소리 복제 |
| s5 대화 | 로컬 대화 테스트 |

## 4층 페르소나 프롬프트

설문, 가족 인터뷰, 통화 전사에서 페르소나 명세(spec) 하나를 채우고, 명세를 4개 층의 지시문으로 바꿉니다. 칸마다 어디서 온 내용인지 기록이 남습니다.

```text
설문 작성본 ── 규칙 ─────────────────┐
가족 인터뷰 ── LLM + 근거 줄 검증 ────┼─▶ spec.json ─▶ L1 공통 규칙 / L2 개인 정보 / L3 관계, 호칭 / L4 말투
통화 전사 ──── 통계 (말투, 주고받기) ──┘
```

| 층 | 내용 |
|---|---|
| L1 공통 규칙 | 대화 흐름, 사용자 식별, 기억 쓰는 법, 말하는 형식, 안전 |
| L2 개인 정보 | 정체, 기본 정보, 성격, 가치관, 상황별 반응, 주제 등급 |
| L3 관계, 호칭 | 가족마다 부르는 말, 말 높이, 톤, 걱정거리 |
| L4 말투 | 말투 서술, 전사 통계로 만든 말투 카드, 실제로 하던 말 |

## 대화 한 턴

BE가 지시문, 검색한 기억, 대화 이력을 보내면 답과 목소리를 만듭니다. 중간계층(orchestrator)을 켜면 한 턴이 아래 순서로 처리됩니다. 기본은 꺼져 있습니다.

```text
기억 선택 → 사전 판정 (기억에 없는 화제인지) → 지시문 조립 → 답 생성 → 출력 검사 (지어낸 이름, 숫자 등)
```

## 폴더

```text
infra/          서버 설정, API 라우트, 스키마, 외부 API 연동
pipeline/       제작 파이프라인 s0~s5, persona_prompt (4층 프롬프트 생성기)
orchestrator/   대화 한 턴의 중간계층 (계약: orchestrator/CONTRACT.md)
prompts/        공통 규칙 모듈(rules/), 상황별 층 구성(layers.json)
tools/          수동 제작 페르소나 내보내기
docs/           설문 양식, 운영 가이드
test/           자동 테스트 (외부 API 호출 없음)
```

녹음, 설문 작성본, 파이프라인 산출물 같은 개인 데이터는 git에 넣지 않습니다.

## 실행

```bash
python3.11 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev,orchestrator]"
cp .env.example .env               # API 키 입력
uvicorn main:app --reload --port 8001
python -m pytest test
```

API 문서는 `http://localhost:8001/docs` 에 있습니다.

## 사용 모델

| 기능 | 모델 |
|---|---|
| 페르소나 응답, 녹음 분석, 기억 추출, 전사 교정 | `gpt-6-luna` |
| 녹음 전사와 화자 분리 | ElevenLabs Scribe `scribe_v2` |
| 목소리 기반 화자 식별 | SpeechBrain ECAPA-TDNN |
| 기억과 질문 임베딩 | `text-embedding-3-small` |
| 목소리 복제, 음성 합성 | Fish Audio `drama-3` |

환경 변수, 수동 제작, 목소리 API, 배포는 [운영 가이드](docs/운영.md)에 있습니다.
