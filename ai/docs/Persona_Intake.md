# TalkTo Voice Persona — Persona Intake v3.0

**기록 기반 Voice Persona 제작을 위한 수집 설문 · 앱 입력 기준**

작성일: 2026-06-04 (v1.0) · 2026-07-28 (v2.0) · **개정일: 2026-09-01 (v3.0)**
**v3.0 개정 이유:** ① 앱 셀프서브 입력 전제(3티어 BM)로 전환 ② 세그먼트 고정(S1~S4)을 **범용 축 구조**로 일반화 — 우리가 생각하지 못한 고객에게도 작동해야 한다 ③ LFA 벤치마크 반영: **종착지(v0 페르소나)가 먼저, 심화는 나중에** — 일괄 설문의 숙제감 제거 ④ 질문을 시제·인칭 중립 "질문 코어"로 저장하고 앱이 문형을 치환.
**중요:** 본 문서는 법적 동의서가 아니다(음성 특징정보·AI 처리·국외이전·사후 사용 동의는 별도 절차). **영업비밀 — 외부 공유 금지.**

# PART 0. 설계 원칙 (기획·개발 공유용)

## 0-1. 세그먼트가 아니라 축(axis)으로 판별한다

고객을 미리 정의된 유형에 끼워 맞추지 않는다. 어떤 조합이든 아래 3개 축의 답으로 Intake가 조립된다.

| 축 | 값 | 결정되는 것 |
|---|---|---|
| **A. 답변 주체** | 본인(1인칭) / 타인·가족(3인칭) / 혼합 | 문형(나는~ / 그분은~), 검수 주체(본인 / 작성 가족) |
| **B. 대상자 상태** | 대화 가능(생존·소통 가능) / 대화 불가(사별·소통 불가) | 시제(현재형/과거형), 목소리 원천(신규 녹음 가능 / 보유 자료만), 동의 경로(본인 동의 / 가족동의+증빙), 성장형 페르소나 적용 여부 |
| **C. 시점** | 지금 이 모습 / 과거의 특정 시기 | 페르소나의 지식 범위·기억 필터 |

- 기존 세그먼트는 조합의 별칭일 뿐이다: 사별 유족=타인·불가·과거 / 시니어 본인 기록=본인·가능·지금 / 치매 가족=혼합·가능·지금(동의 능력 절차, **법률 검토 전 실사용 금지**) / 어린 자녀=타인(부모)·가능·지금(**법률 검토 전 실사용 금지**).
- 예상 밖 고객도 같은 축으로 처리된다: 멀리 사는 조부모(타인·가능·지금), 군 입대 전 자기 기록(본인·가능·지금), 오래 못 뵌 은사(타인·가능·과거), 이민 간 가족(혼합·가능·지금) 등.
- **하드 제약(축과 무관):** 동의 없는 타인 페르소나 제작 불가 / 대화 불가 대상은 가족동의서+관계 증빙+검수 게이트 필수 / 치매·미성년은 법률 검토 전 실사용 금지.

## 0-2. 3층 수집 구조 — "완벽한 설문 후 제작"이 아니라 "빠른 v0 후 성장"

| 층 | 무엇 | 시점 | 분량 |
|---|---|---|---|
| **L1 Core Intake** | 필수 8문항 + 관계 설정 | 음성 업로드 직후, 페르소나 생성 전 | 5~10분 |
| **L2 성장 질문** | 심화 모듈의 문항을 "오늘의 질문" 카드로 분산 + 대화 중 결손 질문(아웃오브캐릭터) | v0 생성 후, 원할 때 | 하루 1~3문항 권장 |
| **L3 보완 인터뷰** | 데이터 부족 영역만 골라 묻는 집중 세션 (Premium은 직원 진행) | 페르소나 품질 미달 시 / Premium 착수 시 | 영역별 10~20분 |

- 모든 답변은 **음성 우선**(전사 → 기억 데이터 + 본인 답변 시 말투·음성 데이터), 텍스트 대체 허용.
- 모든 답변에 자동 태깅: 출처(본인/가족/추정) · 확실성 · 민감도 · AI 사용 범위. "실제 발화"와 "그랬을 것 같다"의 구분이 품질과 안전의 핵심.
- 답변 건너뛰기·"오늘은 여기까지"는 1급 기능. 대화 불가 대상(작성자=유족)의 질문 순서는 **감정 안전 순**: 감각·일상 기억 → 관계·가치관 → 상실 관련은 맨 뒤 선택.
- 답변마다 종착지 표시: "이 답변은 페르소나의 ○○(말투/기억/금기)가 됩니다."

## 0-3. 앱 입력 플로우 (확정 제안)

```
음성 업로드(통화 녹음 등) → 화자 확인(1탭) → [L1 Core Intake 8문항 + 관계 설정]
→ 페르소나 v0 생성(결제 후) → 대화 시작
→ L2: 홈 "오늘의 질문" 카드 + 대화 종료 시 결손 질문 2~3개
→ 데이터 현황 화면: 영역별 확보/부족 표시 → 부족 영역 탭하면 해당 모듈 L3 진입
```

# PART 1. 관계 설정 (L1 필수 — Core 이전 1분)

| 항목 | 입력 | 비고 |
|---|---|---|
| 누구의 페르소나인가요? | 성함/호칭 | |
| 나와의 관계 | 본인 / 부모 / 조부모 / 배우자 / 자녀 / 형제자매 / 친구 / 스승 / 직접 입력 | **목록에 없으면 직접 입력** — 축 구조라 어떤 관계든 처리 |
| 그분과 지금 대화할 수 있나요? | 예 / 아니요(사별) / 아니요(소통이 어려움) | 축 B 판별. "소통이 어려움" 선택 시 안내 후 잠금(법률 검토 전) |
| 어느 시점의 모습을 남기고 싶나요? | 지금 이 모습 / 특정 시기(연도·시기 입력) | 축 C. "왜 이 시점인가요?"(선택, 음성) — 정서적 중심 |
| 페르소나가 나를 부를 호칭 | 예: 우리 딸, 준혁아, 이름 | |
| 함께 쓸 가족 | 초대 목록(선택) | |

# PART 2. L1 Core Intake — 필수 8문항

*말투 객관식 4 + 성격·관계 주관식 3 + 가드레일 1. LFA Memory Lane 구조를 벤치마크하되 한국어 관계 문화에 맞게 재설계. 문형은 축 A에 따라 자동 치환: [본인] "나는~" / [타인] "그분은~".*

| # | 질문 코어 | 형식 | 페르소나에 반영되는 것 |
|---|---|---|---|
| C1 | 말할 때 보통 — 짧고 간결하게 / 보통 / 길고 자세하게 | 객관식 | 응답 길이 |
| C2 | 이야기할 때 — 경험담을 들려주는 편 / 바로 답을 주는 편 / 되물어보는 편 | 객관식 | 응답 형식 |
| C3 | 상대가 힘들어하면 — 같이 울고 웃는 편 / 담담하게 들어주는 편 / 말없이 곁에 있는 편 | 객관식 | 정서 반응 |
| C4 | 고민을 들으면 — 해결책을 주는 편 / 편들어주는 편 / 스스로 답 찾게 돕는 편 / 상황따라 | 객관식 | 조언 스타일 |
| C5 | 처음 만난 사람에게 [본인: 나를 / 타인: 그분을] 소개한다면 어떤 사람인가요? | 주관식·음성 권장 | 성격 핵심 |
| C6 | 사랑하는 사람에게 마음을 어떻게 표현하나요[표현했나요]? — 말·행동·음식·전화 등 실제 방식 | 주관식·음성 권장 | 애정 표현 방식 |
| C7 | [본인: 내가 / 타인: 그분이] 자주 하는[하던] 말이나 입버릇 3가지 — 실제 표현 그대로 | 주관식·음성 권장 | 시그니처 표현 |
| C8 | **이 페르소나가 절대 하지 않아야 할 말이나 행동은?** | 주관식 | 가드레일(최우선 적용) |

- C7에서 [타인] 작성 시: "직접 들은 말"인지 "그랬을 것 같은 말"인지 선택 필수.
- Core 완료 화면: "이제 ○○님의 페르소나가 만들어집니다. 대화하고 답할수록 더 그분다워져요."

# PART 3. L2 표준 모듈 (전 고객 공통 · 선택·순서 자유 · "오늘의 질문"으로 분산 노출)

*각 모듈의 질문 코어는 v2.0 문항과 고정 질문 리스트(A~P)를 승계·통합. 앱 노출 시 축 A·B에 따라 인칭·시제 치환. 모듈 마지막은 항상 오픈엔더: "이 이야기에서 더 남기고 싶은 사람이나 장면이 있나요?" (LFA 패턴 채택)*

## M1. 기본 프로필 (7문항)
출생 연도·고향 / 자란 곳과 그곳의 기억 / 거주 이력 / 학력·일·생업(전업주부·농사·장사 포함 모두) / 가족 내 역할 / 종교·신앙·기도 습관 / 한 문장으로 표현하면

## M2. 가족·관계 지도 (관계당 1카드)
호칭(서로 부르는 방식) / 관계 맥락·대표 기억 / 그 사람에게 자주 하는[하던] 말 / 특히 가까운 사람과 이유 / 자주 걱정하는 가족과 걱정 주제 / 조심해야 할 관계(민감도 高 — 페르소나가 먼저 언급 금지)

## M3. 말투·표현 사전 (10문항)
전화 첫마디 / 끊을 때 마지막 말 / 자주 쓰는 말 10개(실제/추정 구분) / 좋은 소식 반응 / 걱정할 때 하는 말 / 화날 때 말투(금지 표현 포함) / 위로 방식 / 웃을 때·감탄사 / 사투리·억양 / 피해야 할 말투

## M4. 성격·가치관 (8문항)
성격 키워드 3~5 / 가장 중요하게 여기는 것 / 돈·소비 태도 / 일·성실함에 대한 생각 / 갈등 시 행동 / 약속·예의에 대해 하는 말 / 신앙·죽음에 대한 생각(민감도 지정) / "그분답지 않은" 조언은

## M5. 인생 이야기 (장면 회상형 — 세대에 맞는 챕터만)
어린 시절 집의 기억 한 장면 / 학창·청년 시절 이야기 하나 / 배우자와의 만남(해당 시) / 자녀가 어릴 때 기억 한 장면(해당 시) / 일·살림에서 애쓴 이야기 / 가장 행복해 보였던 시기와 장면 / 힘들었던 시기(생략 가능·AI 사용 범위 지정) / 요즘의[말년의] 하루
*문체 원칙: "~에 대해 알려주세요"가 아니라 "~했던 장면 하나를 들려주세요" (LFA 장면 회상형 채택)*

## M6. 감각·일상 기억 (6문항)
대표 음식과 그 음식의 기억 / 음식으로 챙기는 방식 / 자주 주던 선물·챙김 / 자주 있는 장소 / 냄새·소리·물건과 연결된 기억 / 사진·녹음과 연결하면 좋은 기억

## M7. 대표 기억 카드 (8개 이상 권장)
제목 / 내용(장면으로) / 관련 인물·장소·시기 / 감정 태그 / 출처·확실성·민감도·AI 사용 범위

## M8. 상황별 반응 (9문항)
"보고 싶어요" / "너무 힘들어요" / "좋은 일 생겼어요" / 아프다고 할 때(의료 조언 금지 — 식사·휴식·병원 권유만) / 가족끼리 다퉜을 때 / 공부·일 걱정 / 결혼·연애 고민 / 모르는 것을 물었을 때("그건 내가 잘 모르겠구나" 유형) / 돈·상속·정치를 물었을 때(답변 기준)

## M9. 금기·접근 권한 (필수 — v0 생성 전 최소 1회)
주제별 허용/제한/금지 표: 건강·병력 / 사망·장례 / 상속·재산 / 가족 갈등 / 정치 / 종교 / 술·담배 / 생존 가족 사생활 / 후회·미안함 / 기타. 접근 가능 가족 범위. **[본인 작성 시] 본인 지정이 가족 요청보다 우선.**

# PART 4. L3 타겟 선택 모듈 (해당 시에만)

| 모듈 | 대상 조합 | 추가 문항 요지 | 상태 |
|---|---|---|---|
| **T1. 사별 추가** | 타인·대화 불가 | 사망 시기·증빙 / 가족 동의 현황(분쟁 시 제작 보류) / 원본 그대로 듣기 힘든 자료 표시 / 기일·생신 회고 알림 희망 / **성장형 페르소나 안내**(핵심만으로 시작→대화하며 성장) | 사용 가능 |

| **T4. 기념 시점** | 본인·가능·특정 계기(칠순·결혼·입대·유학 등) | 이 계기의 의미 / 이 시점의 나를 대표하는 것 / 몇 년 뒤의 가족에게 | 사용 가능 |
| **T5. 치매 진단 가족** | 혼합·가능·지금 | v2.0 S3 준용(동의 능력 확인 절차·기록 시점 명시) | **법률 검토 전 실사용 금지** |
| **T6. 어린 자녀** | 타인(부모)·가능·지금 | v2.0 S4 준용("지금의 시절 스냅샷"·아이 의사 존중) | **법률 검토 전 실사용 금지** |
