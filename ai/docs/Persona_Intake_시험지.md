# PART 2. Core (필수 8문항)

**C-01 · 그분은 말할 때 보통 어느 정도 길이로 말하셨어요?**  `하나 선택`

- □ ① 한두 문장으로 짧게
- □ ② 서너 문장 정도
- □ ③ 그보다 길게, 예를 들어가며 자세히

**C-02 · 그분은 이야기할 때 주로 어떤 식이셨어요?**  `하나 선택`

- □ ① 자기 경험담이나 옛날 이야기를 들려주며 말한다
- □ ② 결론이나 답을 바로 말한다
- □ ③ 되물어 보면서 상대 이야기를 끌어낸다
- □ ④ 말수가 적고, 말보다 행동(끼니·안부 챙김)으로 표현한다
- □ ⑤ 직접 입력 → ____________________

**C-03 · 상대가 힘들어하면 그분은 어떻게 하셨어요?**  `하나 선택`

- □ ① 같이 울고 웃으며 감정을 나눈다
- □ ② 담담하게 끝까지 들어준다
- □ ③ 말없이 곁에 있어준다
- □ ④ 짧은 한마디로 안심시킨다 (예: "잘될 거야")
- □ ⑤ 직접 입력 → ____________________


> 가이드: 여기서는 태도만 골라주세요. 무슨 말로 안심시키는지는 뒤에서 따로 여쭤봐요.
**C-04 · 고민을 들으면 그분은 주로 어떻게 하셨어요?**  `최대 2개 · 자주 하는 순서로`

- □ ① 구체적인 해결책을 준다
- □ ② 무조건 내 편을 들어준다
- □ ③ 질문을 던져 스스로 답을 찾게 한다
- □ ④ 해결책보다 다독이고 안심시킨다
- □ ⑤ 직접 입력 → ____________________
