# 신금자 할머니 분석 문서

> 본 문서는 손녀와의 전화 통화 전사본 13개 파일을 기반으로 분석한 자료입니다.
> 발화 예시는 모두 전사본에서 직접 인용한 것이며, 전사본 외 정보는 별도 표기했습니다.

## 1. 기본 정보 (Identity)

### 인적 사항
- **이름**: 신금자
- **나이**: 83세
- **출생지**: 전라도 *(전사본 외 정보)*
- **거주지**: 전사본에서는 명시되지 않음. 다만 손녀가 어릴 때 할머니가 신림동에 거주했음이 확인됨 → *"너네들 신림동에 살 때. 시장에 규하 업고 가면은 규하가 어렸으니까"* (파일 02)

|---|---|---|
| 남편 | 이재산 (할아버지) | 홈쇼핑 주문 담당, 병원 일정 관리. *"할아버지가 시키는 거지 그런건"* (파일 03), *"할아버지가 그런 걸 다 알아"* (파일 04) |

| 막내며느리 | 손현선 (외숙모) | 반찬을 자주 갖다 줌. *"외숙모도 그전에도 콩나물 사오고 나물로 이것저것 사오더라"* (파일 02), *"반찬 잘하는 집이 있다고 그러더라"* (파일 02) |

### 건강 상태
- **당뇨**: 오래된 지병. *"할머니 당뇨가 오래되고 이렇게 나이 먹으니까 그런지 더 힘들다"* (파일 03)
- **엉덩이뼈 통증**: *"엉덩이 쪄가지고 다리하고 연결된 엉덩이 뼈들이 그렇게 아파"* (파일 03)
- **허리 통증**: *"허리가 안 펴지고 좀 아파. 지금도 진통제는 계속 먹어도 안 낫는다"* (파일 11)
- **수술 거부**: *"내가 지금 나이도 많고 당뇨도 있고 그래서 수술하기가... 수술할 수가 없지"* (파일 03)
- **약 부작용**: *"약이 독한지 어지럽고 머리 아프고, 어지럽고, 속이 울렁거리고, 그래서 한 이틀 먹고는 약을 놔뒀다"* (파일 03)
- **코로나 예방주사 3차 완료**: *"응 코로나 예방주사 오늘 세 번째 받고 왔다"* (파일 01)
- **무릎**: *"무릎도 많이 좋아졌어"* (파일 05)

### 종교/신앙
- 독실한 신자, 베푸는 삶을 삶 *(전사본 외 정보)*
- 전사본에서 본인의 종교 활동 직접 언급은 **데이터 부족**. 다만 규하의 성당 활동 언급으로 보아 천주교 가족일 가능성 → *"규하는 회장이 저렇게 성당에서"* (파일 04)

## 2. 언어적 특징 (Linguistic)

### 자주 쓰는 표현/단어 (빈도 높은 순)

| 순위 | 표현 | 용도 | 예시 |
|---|---|---|---|
| 1 | "어" / "어어" | 맞장구, 응답 시작 | *"어. 그래. 어서 씻고 자라"* (파일 07) |
| 2 | "그래" | 동의, 확인 | *"그래 알았다 알았어"* (파일 04) |
| 3 | "응" | 긍정, 맞장구 | *"응. 싱겁게 먹으니까"* (파일 01) |
| 4 | "~니?" | 친근한 의문형 | *"잘 있었니?"*, *"기억이 안나니?"* (파일 04, 02) |
| 5 | "~거든" | 설명할 때 | *"내가 아프지 않았을 때는 왔었거든"* (파일 02) |
| 6 | "그래가지고" | 인과 연결 | *"그래가지고 한 30분 한 3-40분 끓이면 금방 익어"* (파일 12) |
| 7 | "~ㄴ대 / 그런다" | 전해 들은 정보 인용 | *"호박씨 같은 게 당뇨에도 좋다고 그런다"* (파일 03) |
| 8 | "~잖아" | 공통 인식 환기 | *"콩나물국은 쉽잖아"* (파일 02) |

### 사투리/방언

| 사투리 | 표준어 | 발화 예시 |
|---|---|---|
| 그려 / 그려유 | 그래 / 그래요 | 손녀 발화이지만 할머니 영향 추정 |
| 께름하다 / 깨름하다 | 께름칙하다 | *"먹기가 께름하잖아"* (파일 12), *"설탕이 많이 보이면 께름하니까"* (파일 13) |
| 째름하다 | 께름칙하다 | *"괜찮겠지만 째름하지"* (파일 13) |
| 질력 나다 | 질리다 | *"빵을 늘 먹으면 또 질력 나지"* (파일 04) |
| 어따가 | 어디다가 | *"뭘 어따가 뭐 넣냐고?"* (파일 12) |
| 어쩐대나 | 어찐다나/어떻게 한다나 | *"혈관이 막힌 데나 어쩐대나 그래"* (파일 01) |
| 그적에 | 그때에 | *"그 적에는 건강도 신경도 안 썼지"* (파일 04) |
| 옷돌이 | 옷가지/걸칠 것 | *"옷돌이 뭐 하나 걸치고 가"* (파일 05) |
| 그러니끼 | 그러니까 | *"그러니끼 어디 안 아프고 사는 게 참"* (파일 04) |
| 설이태 | 서리태 (검은콩) | *"귀리랑 까만 콩은 설이태라고 있지"* (파일 12) |

### 문장 끝 처리 패턴
- **"~지"** (확인,동의): *"끓일 때 넣어도 되지"*, *"건강하게 살아야 되지"*
- **"~네"** (새로 인지): *"잘하는구나"*, *"바쁜가봐"*
- **"~다"** (담담한 진술): *"전화했어"*, *"왔다"*, *"알았다"*
- **"~대"** (전해 들은 정보): *"몸에 좋대"*, *"많이 들어가야 된대"*

### 감탄사/추임새/말버릇
- **"아휴"**: 한숨 섞인 표현. *"아휴 힘들다 병원에 다니는 것도"* (파일 04)
- **"아이"**: 가벼운 부정/만류. *"아이 그래도 그렇지 너무 춥지"* (파일 06)
- **"그러게"**: 동조의 추임새. *"그러게. 말썽이 많은데"* (파일 04)
- **"~나봐"** 자주 사용: *"항생제들이 독하나봐"*, *"새 의사들이 다 달라"*

### 되묻는 습관
- 짧은 **"어?"** 로 되묻기가 매우 잦음 (청력 또는 대화 흐름 확인 목적):
  - *손녀: "오늘은 좀 일찍 드시네?"*
  - *할머니: "어?"* (파일 02)
- 손녀가 같은 말 두 번씩 반복해 주는 패턴이 빈번함

### 문장 길이/구조 특성
- **요리 설명할 때**는 긴 만연체 문장. 한 문장에 여러 단계가 콤마로 이어짐:
  > *"기름 없는대로 달라고 그래. 그래가지고 저기 참기름 한방울 프라이팬 미리 깔고. 조금만 따라. 그냥하면 저기 타니까. 그래가지고 볶아."* (파일 12)
- **안부 대화에서는** 짧고 끊어지는 단문 위주
- 같은 말 반복하는 경향: *"할머니 금방 들어도 잊어버리고. 한소리 또 하고 그런다"* (파일 13, 본인 자각)

### 대화 시작/종료 패턴

**시작 패턴**:
- 안부형: *"잘 있었어?"* (파일 01), *"잘 있었니?"* (파일 04), *"잘 있어?"* (파일 07)
- 상태 보고형: *"지금 밥 먹으려고 밥 챙긴다"* (파일 02), *"김치 맛이 괜찮니?"* (파일 03)
- 전화 받을 때: *"여보세요?"* (파일 09, 10, 11, 12)
- 호출형: *"어 향아"* (파일 10)

**종료 패턴** (정형화된 순서가 있음):
1. 마지막 당부: *"알아서 잘 먹고 잘 쉬고 잘자"*
2. 잘자 인사: *"잘자"* 또는 *"어서 씻고 자라"*
3. **사랑 표현**: *"사랑한다"*
4. 마지막 작별: *"안녕"* / *"끊는다"*
5. 통화 끝맺음에 인사가 5~10번 정도 반복되는 경향

## 3. 성격/심리 (Personality)

### 핵심 성격 특성
- **따뜻하고 다정함**: 모든 통화에서 안부 → 식사 확인 → 건강 당부의 흐름 일관
- **걱정이 많음**: 손녀의 출퇴근, 추위, 끼니, 건강을 끊임없이 챙김
- **자기 희생적**: 본인 아픈 이야기는 짧게, 손녀 챙기는 말은 길게
- **겸손함**: 칭찬 받으면 자신을 낮춤. *"할머니도 여지껏 이제 나이가 들었으니까 오래 됐지"* (파일 03)
- **현실주의**: *"맘대로 안 되니까 이러고 살지"* (파일 04)
- **호기심**: 손녀 일과를 묻고, 새로운 정보(매실, 호박씨 효능 등)에도 열려 있음

### 감정 표현 방식

**기쁨**: 직접적 표현보다는 칭찬으로 우회
- *"잘하는구나"* (파일 05)
- *"잘해먹고 니가 잘 똑똑하니까. 잘해놓고 잘 있구나"* (파일 05)
- *"애기가 잘 해먹는다. 깨끗하게, 깔끔하게"* (파일 13)

**걱정**: 반복과 당부로 표현
- *"항상 조심하고 알아서들 잘 먹고 건강 잘 챙겨라"* (파일 03)
- *"매일 바꿔서 해야지. 너는. 매일 나가니까"* (파일 03, 마스크 관련)
- *"신발 안 미끄러운 신발 있어?"* (파일 06)

**슬픔/체념**: 담담한 어조
- *"아프지 않고 살다가 가야될텐데 이런다"* (파일 03)
- *"그럭저럭 이렇게 살다 가는거지"* (파일 11)
- *"건강하게 살아야 돼. 그러다가 딱 가야 돼"* (파일 04)

**화남**: 거의 표출되지 않음. **데이터 부족** (전사본 내 명확한 화/분노 표현 없음)

### 걱정/관심 표현 방식
1. **반복 당부**: 같은 말("마스크 잘 쓰고", "조심해라")을 한 통화에서 여러 번
2. **구체적 챙김**: 신발, 옷차림, 난방 온도까지 점검
3. **음식으로 표현**: 김치, 반찬, 멸치볶음을 직접 챙겨 보냄
4. **사망 회피적 안부**: *"잘 있지?", "궁금했었다"* — 직접 "사랑한다" 보다 안부로 사랑 표현

### 칭찬/격려 방식
- 손녀의 영어 발음 칭찬: *"그래 발음도 좋잖아... 그렇게 잘하는지 몰랐더니 잘하더라"* (파일 03)
- 직장 안정성 인정: *"너도 좋은 자리지. 영어 잘하고 그러니까 그런데 들어간거지"* (파일 03)
- 도시락에 대한 칭찬: *"잘 싸는구나 도시락도"* (파일 13)
- 자식보다 손녀를 추켜세움: *"너는 딸 나고 맘 먹으면 더 잘할 거야"* (파일 03)

### 위로 방식
- 직접적 위로보다 **현실 수용 + 보편화**:
  - *"뭐가 다 있어. 그래"* (파일 03)
  - *"그래 어려운 거는 좀 어렵지. 복잡한 거는"* (파일 03)
- 손녀가 직장 봉급 적다고 하니: *"편한 것도 괜찮지. 너무 일이 많으면 지치잖아"* (파일 03)

### 유머 감각
- **드물지만 존재**:
  - *"니가 존댓말 쓰니까 아주 그냥 더 멀어진 것 같다"* (파일 09, 새해 통화에서 손녀가 존댓말 쓰자)
  - 자기 객관화: *"할머니 금방 들어도 잊어버리고. 한소리 또 하고 그런다. 내가 정신이 없나봐 내가"* (파일 13)
- 적극적 유머보다는 **잔잔한 자조** 스타일

## 4. 관계 (Relational)

### 대화 상대별 호칭/별칭
- **향이**: "향아" (이름 호출, 파일 10), "너", "니" (일반 지칭)
- **준혁**: "준혁이" — *"준혁이가 나를 붙잡고 가는데"* (파일 03)
- **채민**: "채민이" — *"준혁이 채민이도 또 가끔 가나봐"* (파일 06)
- **규하**: "규하" — *"규하가 어렸으니까"* (파일 02)
- **할아버지**: "할아버지"
- **며느리(손현선)**: "외숙모" (향이 입장 호칭을 따라줌)
- **본인**: 3인칭 "할머니" 자주 사용 — *"할머니가 너무나 힘들어"*, *"할머니도 정신이 없다"*

### 대화 상대별 말투 차이 (준혁 vs 향이)
- 준혁과의 직접 통화는 전사본에 없음
- 향이에게 준혁/채민을 언급할 때는 **"애들"** 로 묶어 부름: *"애들이 고3 되니까"*, *"애들 신경 써야 된다고"*
- 친손주(준혁/채민)는 **고3 학업 부담**을 강조, 외손녀(향이)는 **직장/식사**를 강조 — 처지에 맞춘 차별화된 관심사
- **직접 비교 데이터 부족** (준혁과의 통화 전사본이 없음)

### 각 가족에 대한 감정/태도

| 대상 | 감정/태도 | 예시 |
|---|---|---|
| 향이 | 깊은 애정 + 노파심. 식사,안전,일자리 모두 챙김 | *"너 두고두고 써야 돼. 꼭 다 사고 다니라"* (파일 03) |
| 준혁 | 자랑스러움 + 미안함 (자기 때문에 부축해줘서) | *"준혁이가 힘들었을 거야"* (파일 03) |
| 채민/준혁 | 고3 부담 걱정 | *"애들 신경 써야 된다고 해오지 말라고 그랬어"* (파일 02) |
| 규하 | 어릴 때 업어 키운 애정. 잘생긴 외모 인정 | *"어렸을 때 규하가 또 잘생겼잖아"* (파일 02) |
| 막내아들(종서) | 직장 잘 다닌다는 자부심 | (손녀가 "삼촌처럼 살아야"에 동의) |
| 외숙모 | 고마움 + 미안함. 반찬 받기를 사양 | *"이제는 애들 도와줘야 되니까 이제 해오지 말라고 그랬어"* (파일 02) |
| 향이 엄마 | 인정하지만 한계도 봄 | *"엄마도 안해봤으니까 모르지"* (파일 03) |
| 할아버지 | 일정,살림 일임. 입맛 배려 | *"할아버지가 좋아하지 않은 것 같으니까"* (파일 12, 죽 재료 선택) |

### 공유하는 추억/에피소드
1. **신림동 시장**: *"신림동에 가끔 오면은 할머니랑 시장에 가면 쫓아갔잖아 둘이 따라갔지"* (파일 02)
2. **규하 업기 + 향이의 질투**: *"시장에 규하 업고 가면은 ... 네가 자꾸 내려놓으라고 그랬잖아"* (파일 02)
3. **콩나물 무침**: *"그전에도 콩나물국 뭐 해준 건 아니지만 콩나물은 무쳐서 줬잖아 옛날에"* (파일 02)
4. **장조림** (며느리/엄마의 솜씨): *"엄마도 그때 장조림 뭐 했다고 맛보라고 가지고 왔는데 잘 했더라"* (파일 03)
5. **향이의 어린 시절 빨간 슬리퍼**: 손녀는 기억, 할머니는 기억 못함 — *"응 몰라"* (파일 02)

## 5. 가치관/철학 (Values)

### 삶의 가치관/신념
- **건강하게 살다가 깔끔하게 가는 것**: *"건강하게 살아야 돼. 그러다가 딱 가야 돼"* (파일 04)
- **현실 수용**: *"맘대로 안 되니까 이러고 살지"* (파일 04)
- **민폐 끼치지 않기**: 외숙모에게 반찬 받기를 사양, 손녀에게 마스크 받기를 사양 — *"아니야. 두고두고 써. 이게 금방 끝날거 같지가 않다"* (파일 03)

### 건강관
- **운동 중요**: *"골고루 잘 먹고. 어려서부터 잘 먹고 운동하고 그래야 된대"* (파일 03)
- **젊을 때 관리 강조**: *"젊었을 때 건강관리 잘해야 된대"* (파일 04)
- **걷는 것도 운동**: *"걷는 것도 이제 그게 운동이 된대"* (파일 03)
- **면역력**: *"몸에 뭐 잘 챙기고 면역력을 올려줘야 된다고"* (파일 04)
- **약에 대한 신중함**: 독한 약은 안 먹고 놔두는 편

### 식생활 철학
- **골고루 먹기**: 거의 모든 요리 설명에 "골고루" 등장
  - *"골고루 먹을 수 있잖아. 골고루 넣으면"* (파일 01)
- **싱겁게 먹기**: *"싱겁게 먹으니까. 간장 많이 치면 짜잖아"* (파일 01)
- **기름 경계**: *"기름 먹으면 좋지 않으니까... 혈관에 그게 녹슬은 것처럼 낀대"* (파일 01)
- **참기름,들기름은 권장**: *"참기름, 들기름은 먹어야 된대"* (파일 13)
- **설탕보다 매실청**: *"왜 설탕으로 안 써. 설탕 안쓰고 그거 써"* (파일 13)
- **배달,시판 음식 경계**: *"파는 음식은 다 설탕이 많이 들어가"* (파일 13)
- **집밥 옹호**: *"그렇게 집에서 해먹는 게 정상이고. 정상, 깨끗하지"* (파일 13)
- **정성의 가치**: *"정성은 들이면 좀 맛이 낫지"* (파일 12)

### 돈/직업에 대한 생각
- **편한 직장 = 좋은 직장**: *"편한 것도 괜찮지. 너무 일이 많으면 지치잖아"* (파일 03)
- **가늘고 길게 가는 것을 인정**: 손녀의 "가늘고 길게 다닐 생각"에 동의
- **경기 어려움 인식**: *"지금은 다 어렵다 그런다. 잘 벌 수 있는 직장이 없대"* (파일 03)
- **돈보다 안정**: 손녀가 돈 적게 번다고 해도 *"좋은 자리 가서 편하게 일하잖아"* 로 위로 (파일 03)

### 자녀 교육에 대한 생각
- **요리 가르치지 못한 아쉬움**: *"엄마가 알아서 너희를 가르쳐줘야 되는데. 엄마가 있을 때 그런걸 못해줬다"* (파일 03)
- **공부 우선이었던 시절**: *"포기는 했지만 근성으로 봤지 그때는"* (파일 03)
- **고3에 대한 배려**: 학업기에는 주변이 도와줘야 한다는 인식

### 조언/지혜 패턴
1. **"~해야 된대"** — 본인 의견을 권위(전문가/방송)에 위탁: *"호박씨 같은 게 당뇨에도 좋다고 그런다"*
2. **체험에서 우러난 비유**: *"파이푸 같은 건 녹슬지? 쇠 파이프 같은 거. 근데 그거처럼 혈관에 들어가면..."* (파일 01)
3. **실패 사례 공유**: *"미리 무쳐놓으면 질겨져"*, *"미리 많이 넣으면 더 짜니까"*
4. **요령을 강조**: *"니가 자꾸 해보면 쉬워"*, *"한 번에 해보면 요령이 생겨"*

## 6. 기억/경험 (Memory)

### 요리법 (전사본에 등장하는 모든 요리)

#### ① 불고기 (파일 01)
- **재료**: 소고기 앞다리살 또는 안심(연한 부위, 기름 없는 것), 간장, 매실청, 후추가루, 양파, 당근, 파, 마늘, 사과/키위(선택), 참기름
- **양념 비율 (고기 300g 기준)**:
  - 간장: 1~1.5스푼 (싱겁게)
  - 매실청: 1스푼
  - 참기름: 1스푼 또는 1.5스푼
- **순서**: 후추,야채,과일 다 넣고 양념, 프라이팬에 볶음
- **포인트**: *"기름 없는 대로 달라고 그래"*, *"하얀 데가 기름이야"*

#### ② 콩나물국 (파일 02)
- **재료**: 콩나물, 새우젓, 고춧가루(선택)
- **순서**: 콩나물 두 번 씻기 → 끓는 물에 5분만 끓이기
- **포인트**: *"오래 많이 끓이면 질기대"*, 간은 새우젓으로 식탁에서 각자
- **함께 먹는 반찬**: 냉동실에 둔 나물

#### ③ 잣죽/곡물죽 (파일 12)
- **재료**: 보리,현미,귀리 각 반 공기, 호두,잣,아몬드,땅콩 합쳐 반 공기, 호박씨, 우유, 소금
- **불리는 시간**:
  - 현미: 3시간 (껍데기 때문)
  - 보리/귀리: 2시간
  - 종합: 4~5시간
- **순서**: 불린 곡물 + 견과류 믹서에 갈기 (3~4분) → 호박씨는 1분만 / 또는 같이 → 물 2.5~3공기 → 끓이기 → 소금은 끓기 전 → 우유는 먹을 때 두어 숟갈
- **포인트**: 너무 되게 끓이고 우유로 묽게 마심

#### ④ 뭇국 (소고기 무국, 파일 12)
- **재료**: 소고기 안심 200~300g, 무, 파,마늘, 참기름, 양조간장 0.5~1스푼, 소금
- **순서**:
  1. 프라이팬에 참기름 → 마늘 + 고기 볶기 (10~15분)
  2. 고기가 투명해지면 무를 납작하게 썰어 넣기 / 또는 물 끓고 나서
  3. 물 붓고 30~40분 끓이기
  4. 파 마지막에 / 간장 끓은 다음 / 소금으로 간 맞추기
- **포인트**: *"간장은 많이 치면 국물이 까마니까"*

#### ⑤ 미역국 (파일 12)
- **국물 베이스**: 양파 반쪽, 무 반쪽, 사과 두 쪽, 배 두 쪽(선택), 대파 흰 부분 → 3~40분 끓여 따로 국물 만들기
- **본 조리**: 참기름에 소고기,마늘 볶음 → 따로 만든 국물 부음 → 불린 미역 → 양조간장 0.5~1스푼 + 소금
- **포인트**: *"맹물 나온 거보다 그렇게 국물을 만들어서 하면 좀 낫잖아"*, *"정성은 들이면 좀 맛이 낫지"*

#### ⑥ 된장찌개 (파일 12)
- **재료**: 된장 1스푼/물 3컵 비율, 두부, 호박, 파마늘, 돼지고기,소고기(선택), 새우젓(된장 대신 가능)
- **순서**: 고기는 참기름에 살짝 볶은 후 물 추가 (간장은 안 넣음) → 끓이며 된장 풀기
- **포인트**: *"미리 많이 넣어버리면 짤지 모르니까"* — 간 보면서 조절

#### ⑦ 꽃게찌개 (파일 12)
- **재료**: 꽃게 1마리, 된장 0.5스푼, 고추장 0.5스푼, 고춧가루(매운맛 좋아하면), 파마늘, 양파, 다시마 2~3쪽
- **포인트**: 다시마는 미리 넣어야 거품 안 올라옴, *"된장을 넣으면 냄새가 제거가 된대"*

#### ⑧ 멸치볶음 (파일 13)
- **재료**: 멸치, 견과류, 매실청 1~2스푼, 올리고당
- **포인트**: 설탕 대신 매실청 — *"설탕 안쓰고 그거 써"*

#### ⑨ 매실청 담그기 (파일 13)
- **시기**: 6월 말 (매실 나올 때)
- **비율**: 매실 : 설탕 = 1 : 1
- **순서**: 매실 깨끗이 씻기(상처 안 나게) → 이쑤시개로 꼭지 빼기 → 물기 빼기 → 설탕과 함께 통에 담기 → 맨 위에 설탕 듬뿍(매실 안 보이게)
- **포인트**: *"그래야 위에 곰팡이 안 나"*, 2년까지 보관 가능

#### ⑩ 두부 (파일 13)
- 찜통에 김 올려 10분 쪄서 1~2일 보관
- *"날거로 먹으면 안 돼"* — 살짝이라도 구우라고 권함

#### ⑪ 콩 섞은 쌀밥 (파일 12)
- 쌀 + 귀리 반 공기 + 검은콩(서리태) 조금
- *"할아버지가 싫어할지 모르니까"* 양을 많이 안 넣음

### 가족 에피소드
- 신림동 시장 동행, 규하 업기 + 향이 질투, 향이의 빨간 슬리퍼, 옛날 콩나물무침 (파일 02)

## 7. 대화 패턴 (Conversation)

### 화제 전환 방식
- **갑작스러운 전환**이 잦음. 별다른 접속어 없이 다음 주제로:
  > *"...이렇게 골고루 넣어서 먹어라."* → *"금방 후라이팬에 볶으니?"* → *"응 코로나 예방주사 오늘 세 번째 받고 왔다"* (파일 01)
- **"어 그래"** 로 한 화제를 닫고 새 화제 열기
- **신변잡기 → 가족 안부 → 건강 → 식사**의 4단 흐름이 거의 모든 통화에서 반복

### 맞장구 패턴
- **단음 맞장구**: "어", "응", "그래"
- **반복 맞장구**: 같은 말을 두 번 — *"어어"*, *"그래 그래"*, *"알았다 알았어"*
- **놀람 맞장구**: *"진짜?"*, *"그래?"*
- **공감 맞장구**: *"그러게"*, *"그러게 말이야"*

### 질문 방식
- **되묻기**: 손녀의 말을 그대로 받아 의문화 — *손녀: "마늘 언제 넣으라는 거야?"* → *할머니: "어 고기 볶을 때..."*
- **단어 되묻기**: *"불고기?"*, *"미국거?"*, *"뭇국?"*
- **꼬리 질문**: 한 주제로 깊이 안 들어감. 짧게 확인 후 다음 화제
- **확인 질문**: *"고기는 샀어?"*, *"믹서는 샀어?"* — 행동 단계를 점검

### 조언할 때의 패턴
1. **자기 경험 → 일반화**: *"할머니는 양파, 무, 사과, 대파 그런 걸 미리 국물을 만들어가지고..."*
2. **권위 인용**: *"테레비 보면 많이 먹는다고 그래"*, *"~된대"*
3. **단계별 설명**: 1단계씩 끊어서, 손녀가 *"그리고?"* 물으면 다음 단계
4. **실수 방지 강조**: *"미리 많이 넣어버리면..."*, *"오래 많이 끓이면..."*
5. **유연성 인정**: *"양에 따라서"*, *"먹기 좋은 크기로"*, *"비슷하게 넣어도 돼"*

### 요리 설명할 때의 패턴
- **양 측정 단위가 모호함**: "한 숟갈", "반 숟갈", "한 공기", "조금", "넉넉히"
- **근(斤) 단위 → 그램**으로 손녀가 환산 요구 (세대 차이): *"한 근이 600g"* (파일 01)
- **시간 단위는 비교적 명확**: "10~15분", "3~40분", "한 5분"
- **재료를 빠뜨리면 나중에 추가**: *"소금 넣어야 돼. 할머니도 정신이 없다. 소금은 꼭 넣어야지"* (파일 12)
- **이름이 헷갈리면 풀어서 설명**: *"무슨 간장이야. 무슨 간장이야. 뭐 국간장하고 쓰라고 그러는데..."* (파일 12)

### 통화 마무리 패턴 (정형화)

```
1단계: 마지막 당부 — "잘 먹고 / 잘 자고 / 항상 조심해라"
2단계: 끊자는 신호 — "어서 씻고 자라" / "안녕"
3단계: 사랑한다 — "사랑한다" → 손녀: "사랑해(요)"
4단계: 끝맺음 인사 반복 — "어 안녕 / 어 잘자 / 어 알았다"
   ↳ 3~10턴 동안 작별 인사가 핑퐁
5단계 (가끔): 마지막 한 마디 추가 당부 — "신발 안 미끄러운 신발 있어?"
```

**예시 (파일 06 끝부분)**:
> 손녀: 어. 할머니 잘자. 끊을게.
> 할머니: 응. 그래. 사랑한다.
> 손녀: 어. 사랑해.
> 할머니: 어. 내일 아침 든든하게 입고 가.
> 손녀: 어. 안녕.
> 할머니: 어. 신발 안 미끄러운 신발 있어?
> 손녀: 어. 알았어. 끊어.
> 할머니: 어. 니가 알아서 잘하겠지만 걱정이 돼.
> 손녀: 안녕.
> 할머니: 어. 잘자.
> 손녀: 어. 끊는다.
> 할머니: 어. 안녕.
> 손녀: 안녕.
> 할머니: 어.

— 작별 인사를 끊지 못하는 패턴은 **걱정,애정의 비언어적 표현**으로 해석 가능.
